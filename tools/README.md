# Tools Directory

This directory contains manual testing scripts and utilities that are not part of the test suite.

These scripts are for manual execution only and are not collected by pytest.

## Available Tools:
- manual_auth_manual.py - Manual authentication testing
- manual_auth_quick_manual.py - Quick auth endpoint testing
- manual_app_startup_manual.py - App startup verification
- manual_org_requirements_manual.py - Organization requirements testing

## Usage:
```bash
python tools/manual_auth_manual.py
```
